# Tambo AI Shopping Assistant

Sistema de asistente de compras con IA que permite orientar a clientes mediante un chatbot y visualizar información relevante desde un dashboard administrativo.

## Funcionalidades principales

- Chatbot de atención al cliente
- Consulta de productos
- Recomendación asistida por IA
- Dashboard administrativo
- Registro de interacciones

## Arquitectura

El sistema sigue una arquitectura por capas:

- Capa de presentación
- Capa de aplicación
- Capa de servicios IA
- Capa de datos
