# **Definition of Done (DoD)**

## **Criterios Generales**

Toda funcionalidad del proyecto será considerada terminada cuando:

- El desarrollo fue implementado correctamente.  
- El código fue integrado al repositorio.  
- No existen errores críticos.  
- Se realizaron pruebas funcionales básicas.  
- La documentación fue actualizada.  
- El Issue correspondiente fue actualizado.  
- Se realizó Pull Request cuando fue necesario.  
- La funcionalidad cumple con los requisitos definidos en el Sprint Backlog.

# **DoD en Sprint 1:**

## **HU-01 / PB-01: Consultar promociones vigentes**

La Historia de Usuario se considera terminada cuando:

1. El usuario puede solicitar promociones mediante el chatbot.  
2. El chatbot identifica correctamente la intención relacionada con promociones.  
3. El backend consulta las promociones activas desde Supabase.  
4. La información retornada contiene datos válidos.  
5. El frontend muestra correctamente las promociones encontradas.  
6. Se visualiza al menos nombre, descripción y precio promocional.  
7. La funcionalidad fue probada en la rama Test.  
8. No existen errores críticos durante la consulta.  
9. Se realizó Pull Request.  
10. La documentación fue actualizada.

## **HU-02 / PB-02: Buscar productos por nombre o categoría**

La Historia de Usuario se considera terminada cuando:

1. El usuario puede buscar productos desde el chatbot.  
2. El chatbot interpreta correctamente la búsqueda.  
3. El backend realiza consultas a Supabase.  
4. La búsqueda funciona por nombre.  
5. La búsqueda funciona por categoría.  
6. El sistema retorna únicamente productos activos.  
7. El frontend muestra los resultados encontrados.  
8. Se realizaron pruebas funcionales.  
9. No existen errores críticos.  
10. Se realizó Pull Request.  
11. La documentación fue actualizada.

## **HU-04 / PB-04: Carrito de compras básico**

La Historia de Usuario se considera terminada cuando:

1.  El usuario puede agregar productos al carrito.  
2. El usuario puede visualizar los productos agregados.  
3. El sistema calcula correctamente el total.  
4. El usuario puede eliminar productos del carrito.  
5. La interfaz actualiza la información correctamente.  
6. Se realizaron pruebas funcionales.  
7. No existen errores críticos.  
8. Se realizó Pull Request.  
9. La documentación fue actualizada.
