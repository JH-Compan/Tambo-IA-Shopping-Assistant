# **Sprint 2 – Chatbot Funcional**

## **Proyecto**

Tambo AI Shopping Assistant (Tambot)

## **Duración del Sprint**

\[Colocar fecha de inicio\] – \[Colocar fecha de finalización\]

## **Objetivo del Sprint**

Completar las funcionalidades principales pendientes del chatbot para disponer de una versión funcional e integrada del sistema, incorporando recomendaciones de productos, validación de stock, resumen de pedido, registro de interacciones y documentación final.

# **Sprint Goal**

Contar con una versión completa y demostrable de Tambot, capaz de interactuar con los usuarios mediante una interfaz conversacional, consultar información almacenada en Supabase y ofrecer funcionalidades avanzadas relacionadas con el proceso de compra.

# **Product Backlog Seleccionado**

| ID  | Historia de Usuario  |
| :---- | :---- |
| PB-03  | Como cliente nuevo de Tambo, quiero recibir recomendaciones de productos populares para conocer opciones destacadas.  |
| PB-05  | Como cliente frecuente, quiero recibir recomendaciones basadas en compras anteriores para ahorrar tiempo al elegir productos.  |
| PB-06  | Como cliente, quiero que el sistema valide la disponibilidad de stock antes de recomendar productos.  |
| PB-07  | Como cliente, quiero visualizar un resumen final de mi pedido antes de finalizar la compra.  |
| PB-08  | Como administrador, quiero registrar y gestionar información e interacciones del sistema para mantener actualizada la simulación.  |

# **Actividades Planificadas**

- Implementar recomendaciones para clientes nuevos.  
- Preparar historial de compras simulado en Supabase.  
- Implementar validación básica de stock.  
- Implementar resumen final del pedido.  
- Registrar interacciones básicas del chatbot.  
- Documentar evidencias finales del proyecto.  
- Preparar la demostración final del sistema.

# **Riesgos Identificados**

- Problemas de integración entre frontend, backend y Supabase.  
- Inconsistencias en los datos utilizados para recomendaciones.  
- Errores en la validación de stock.  
- Retrasos en la documentación y evidencias finales.  
- Tiempo limitado para pruebas completas antes de la demostración.

# **Entregables Esperados**

- Sistema con recomendaciones básicas funcionales.  
- Validación de stock integrada al flujo del chatbot.  
- Resumen final de pedido operativo.  
- Registro de interacciones almacenado en Supabase.  
- Evidencias documentadas del Sprint 2\.  
- Versión demostrable de Tambot para presentación final.

# **Resultado Esperado**

Al finalizar el Sprint 2, el equipo espera contar con una versión funcional completa del sistema Tambot, integrando las funcionalidades principales definidas en el Product Backlog y disponiendo de la documentación necesaria para su evaluación y demostración.
