# **Objetivo del Sprint**

Completar las funcionalidades principales del sistema Tambot mediante la implementación de recomendaciones, validación de stock, resumen de pedido, registro de interacciones y preparación de la demostración final del proyecto.

Contar con una versión completamente funcional del chatbot que permita recomendar productos, validar disponibilidad, registrar interacciones y mostrar un resumen de compra utilizando Supabase como fuente de datos.

# **Riesgos Identificados**

- Problemas de integración entre frontend y backend.  
- Errores de acceso o permisos en Supabase.  
- Inconsistencias en los datos utilizados para recomendaciones.  
- Tiempo limitado para pruebas finales y documentación.

# **Resultado Esperado**

Al finalizar el Sprint 2 se espera contar con una versión demostrable de Tambot que integre recomendaciones, validación de stock, resumen de compra y registro de interacciones, además de la documentación necesaria para la presentación final del proyecto.
