# Sprint Backlog - Tambo AI Shopping Assistant / Tambot

El Sprint Backlog organiza las tareas seleccionadas para cada sprint del proyecto. A diferencia del Product Backlog, que contiene todas las funcionalidades del producto, el Sprint Backlog detalla las actividades concretas que el equipo realizará durante un sprint específico.


## Sprint 1 - Primera versión funcional

**Objetivo del Sprint 1:**  
Construir la primera versión funcional del chatbot, permitiendo consultar promociones, buscar productos y agregar productos a un carrito básico.

| ID | Tarea | Product Backlog relacionado | Responsable | Prioridad | Estado |
|---|---|---|---|---|---|
| T-S1-01 | Crear la pantalla principal del chatbot en HTML | PB-01 / PB-02 | Frontend | Alta | Pendiente |
| T-S1-02 | Diseñar los estilos visuales del chatbot con CSS | PB-01 / PB-02 | Frontend | Alta | Pendiente |
| T-S1-03 | Implementar el flujo básico de conversación | PB-01 / PB-02 | Frontend / Lógica | Alta | Pendiente |
| T-S1-04 | Implementar consulta de promociones vigentes | PB-01 | Lógica / Datos | Crítica | Pendiente |
| T-S1-05 | Implementar búsqueda de productos por nombre o categoría | PB-02 | Lógica / Datos | Alta | Pendiente |
| T-S1-06 | Preparar datos de productos y promociones en Excel | PB-01 / PB-02 | Datos | Alta | Pendiente |
| T-S1-07 | Implementar carrito de compras básico | PB-04 | Frontend / Lógica | Alta | Pendiente |
| T-S1-08 | Registrar evidencias del Sprint 1 | Evidencias | Equipo | Media | Pendiente |
