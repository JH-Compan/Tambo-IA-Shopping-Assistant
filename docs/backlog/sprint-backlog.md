# Sprint Backlog - Tambo AI Shopping Assistant / Tambot

El Sprint Backlog organiza las tareas seleccionadas para cada sprint del proyecto. A diferencia del Product Backlog, que contiene todas las funcionalidades del producto, el Sprint Backlog detalla las actividades concretas que el equipo realizará durante un sprint específico.


## Sprint 1 - Primera versión funcional

**Objetivo del Sprint 1:**  
Construir la primera versión funcional del chatbot, permitiendo consultar promociones, buscar productos y agregar productos a un carrito básico.

| ID | Tarea | Historia relacionada | Responsable | Prioridad | Estado |
|---|---|---|---|---|---|
| T-S1-01 | Crear la pantalla principal del chatbot en HTML | HU-01 / HU-02 | Frontend | Alta | Pendiente |
| T-S1-02 | Diseñar los estilos visuales del chatbot con CSS | HU-01 / HU-02 | Frontend | Alta | Pendiente |
| T-S1-03 | Implementar el flujo básico de conversación | HU-01 / HU-02 | Frontend / Lógica | Alta | Pendiente |
| T-S1-04 | Implementar consulta de promociones vigentes | HU-01 | Lógica / Datos | Crítica | Pendiente |
| T-S1-05 | Implementar búsqueda de productos por nombre o categoría | HU-02 | Lógica / Datos | Alta | Pendiente |
| T-S1-06 | Preparar datos de productos y promociones en Excel | HU-01 / HU-02 / HU-08 | Datos | Alta | Pendiente |
| T-S1-07 | Implementar carrito de compras básico | HU-06 | Frontend / Lógica | Alta | Pendiente |
| T-S1-08 | Probar consulta de promociones, búsqueda y carrito | HU-01 / HU-02 / HU-06 | Pruebas | Media | Pendiente |
| T-S1-09 | Registrar evidencias del Sprint 1 | Evidencias | Equipo | Media | Pendiente |

## Estados sugeridos

| Estado | Significado |

| En proceso | La tarea se está desarrollando. |
| En revisión | La tarea fue terminada y está siendo revisada. |
