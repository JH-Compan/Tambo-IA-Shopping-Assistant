# Historias de Usuario - Tambo IA Asistente de Compras

| ID | Historia de Usuario | Prioridad | Criterios de Aceptación | Escenario |
|---|---|---|---|---|
| HU-01 | Como cliente de Tambo, quiero consultar promociones vigentes desde una simulación de chatbot web para encontrar ofertas disponibles de forma rápida. | 🔴 Crítica | 1. Mostrar promociones vigentes.<br>2. Obtener promociones desde Excel.<br>3. Respuesta clara y breve.<br>4. Mostrar nombre, precio y vigencia. | **Consulta de promociones**<br>Dado que el cliente escribe “¿Qué promociones hay?”, cuando el chatbot procesa la consulta, entonces muestra promociones vigentes registradas en Excel. |
| HU-02 | Como cliente de Tambo, quiero buscar productos por nombre o categoría desde el chatbot web para conocer rápidamente su precio, disponibilidad y opciones similares. | 🟠 Alta | 1. Buscar por nombre o categoría.<br>2. Consultar información desde Excel.<br>3. Mostrar precio y disponibilidad.<br>4. Sugerir alternativas similares. | **Búsqueda de producto**<br>Dado que el cliente escribe “¿Tienen gaseosa?”, cuando el chatbot consulta Excel, entonces muestra gaseosas disponibles con precio y stock. |
| HU-03 | Como cliente nuevo de Tambo, quiero que el chatbot web me sugiera productos más vendidos para conocer opciones populares aunque no tenga historial de compra. | 🟠 Alta | 1. Detectar usuarios sin historial.<br>2. Consultar productos más vendidos desde Excel.<br>3. Mostrar recomendaciones claras.<br>4. Permitir agregar productos al carrito. | **Cliente nuevo**<br>Dado que el cliente no tiene historial, cuando inicia la conversación, entonces el chatbot muestra productos populares. |
| HU-04 | Como cliente frecuente de Tambo, quiero recibir recomendaciones basadas en mis compras anteriores para ahorrar tiempo al elegir productos. | 🟠 Alta | 1. Identificar usuario.<br>2. Consultar historial en Excel.<br>3. Sugerir productos relacionados.<br>4. Mostrar precio y agregar al carrito. | **Cliente frecuente**<br>Dado que el cliente tiene historial, cuando solicita recomendaciones, entonces el chatbot muestra productos relacionados. |
| HU-05 | Como cliente de Tambo, quiero que el sistema valide el stock de los productos recomendados para no elegir productos agotados. | 🟡 Media | 1. Consultar stock desde Excel.<br>2. Mostrar disponibilidad.<br>3. Sugerir alternativas si no hay stock.<br>4. Actualizar recomendaciones según disponibilidad. | **Producto agotado**<br>Dado que un producto no tiene stock, cuando el chatbot revisa disponibilidad, entonces ofrece un sustituto. |
| HU-06 | Como cliente de Tambo, quiero agregar productos recomendados o promocionados a un carrito para armar mi pedido dentro de la simulación web. | 🟠 Alta | 1. Agregar productos desde recomendaciones.<br>2. Mostrar cantidad agregada.<br>3. Calcular subtotal y total.<br>4. Permitir seguir agregando productos. | **Agregar al carrito**<br>Dado que el cliente visualiza una promoción, cuando selecciona “Agregar al carrito”, entonces el producto se guarda y actualiza el total. |
| HU-07 | Como cliente de Tambo, quiero visualizar y confirmar el resumen de mi pedido para revisar productos y total antes de finalizar la simulación. | 🟡 Media | 1. Mostrar productos del carrito.<br>2. Mostrar cantidades y totales.<br>3. Permitir modificar productos.<br>4. Generar código de pedido simulado. | **Confirmación de pedido**<br>Dado que el cliente tiene productos en el carrito, cuando confirma el pedido, entonces el sistema muestra el resumen final y el código generado. |
| HU-08 | Como administrador de Tambo, quiero gestionar información de productos, promociones, stock e interacciones mediante Excel para mantener actualizada la simulación. | 🟠 Alta | 1. Excel debe contener productos y promociones.<br>2. El sistema debe leer Excel.<br>3. Permitir actualizar datos.<br>4. Reflejar cambios en el chatbot. | **Actualización de datos**<br>Dado que el administrador actualiza el stock en Excel, cuando el chatbot consulta un producto, entonces muestra la disponibilidad actualizada. |
